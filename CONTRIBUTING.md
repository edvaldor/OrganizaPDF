# Como contribuir

Contribuições são bem-vindas por meio de issues e pull requests.

1. Crie um fork e uma branch para a alteração.
2. Instale as dependências com `python -m pip install -e ".[dev]"`.
3. Execute `python -m unittest discover -s tests -v` e `ruff check .`.
4. Descreva no pull request o problema resolvido e como a alteração foi testada.

Não inclua PDFs pessoais, documentos confidenciais ou arquivos protegidos por direitos autorais nos testes.
